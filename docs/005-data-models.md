# 005 Data Models

## Runtime Decision Model
Produced by `build_response()` in [server/ws_server.py](../server/ws_server.py).

Fields:
- `type`: always `final` for terminal decisions
- `label`: decision enum (`HUMAN`, `MACHINE`)
- `decision`: duplicate of `label` for compatibility
- `confidence`: rounded float
- `proba_human`: derived probability for the human class
- `proba_machine`: derived probability for the machine class
- `transcript`: transcript excerpt truncated to 100 characters
- `method`: decision path identifier
- `elapsed_ms`: integer latency in milliseconds
- `number`: call number when present in config
- `audio_start_time`: human-readable bracketed timestamp
- `audio_start_timestamp`: ISO start timestamp
- `audio_end_time`: human-readable bracketed timestamp
- `audio_end_timestamp`: ISO end timestamp
- `audio_duration_sec`: derived duration between start and end times when available

## WebSocket Config Model
Input JSON consumed by the websocket handler.

Fields:
- `config.Number`: external call or customer number
- `config.VID`: external call identifier
- Optional runtime keys accepted by `apply_runtime_config()`:
  - `MAX_CALL_SEC`
  - `SILENCE_RMS_THRESHOLD`

Validation:
- Unknown runtime keys are ignored.
- Accepted values are clamped to configured ranges.

## AGI Variable Output Model
Emitted by [amd.py](../amd.py) to Asterisk:
- `AMDSTATUS`
- `AMDCAUSE`
- `AMDTRANSCRIPT`
- `AMDELAPSED`
- `AMDMETHOD`
- `AMDCONFIDENCE`
- Optional probability variables: `AMDPROBAHUMAN`, `AMDPROBAMACHINE`

## Elasticsearch Log Model
Generated by `ElasticLogger.log_response()` in [elastic_logger.py](../elastic_logger.py).

Fields include:
- `_ts_sec` (internal worker timestamp)
- `connection_id`, `customer_number`, `vid`
- `decision`, `decision_type`, `confidence`
- `proba_human`, `proba_machine`
- `method`, `transcript`, `transcript_length`, `has_transcript`
- `audio_duration_sec`, `bytes_received`, `response_time_ms`
- `audio_url`
- `audio_start_time_str`, `audio_end_time_str`

Persistence model:
- Documents are indexed under `amd-stats-YYYY.MM.DD`.
- Queue and buffer stats are maintained by the worker.
- Bulk flush is size- and time-driven.

## Audio Upload Task Model
Defined in [audio_logger.py](../audio_logger.py).

Task payload fields:
- `audio_data`
- `conn_id`
- `customer_number`
- `vid`
- `decision`
- `transcript`
- `confidence`
- `timestamp`

Operational stats:
- `stored`, `failed`, `queue_size`, `last_error`, `last_success`, `reconnects`

## Training Data Models
1. Whisper fine-tuning CSV in [scripts/finetune_whisper_small.py](../scripts/finetune_whisper_small.py):
- required columns: `path` and `transcription` or `text`

2. Classifier CSV in [scripts/train_text_cls.py](../scripts/train_text_cls.py):
- required columns: `text`, `label`
- expected labels mapped to enum values (`HUMAN` -> `0`, `MACHINE` -> `1`)

3. Bulk evaluation output CSV in [scripts/bulk_ws_eval.py](../scripts/bulk_ws_eval.py):
- columns: `file,type,label,confidence,proba_human,transcript,elapsed_ms`

## Model Artifact Data Contracts (Deep Coverage)
### CTranslate2 Whisper Artifact Set
Location: [models/whisper-ct2](../models/whisper-ct2)
- `config.json`: model architecture and suppression/alignment metadata
- `generation_config.json`: decoder generation behavior and language identifiers
- `tokenizer.json`, `tokenizer_config.json`, `vocab.json`, `merges.txt`, `vocabulary.json`: tokenizer assets
- `preprocessor_config.json`, `normalizer.json`, `special_tokens_map.json`: preprocessing and token definitions

### Fine-Tuned Whisper Checkpoint Set
Location: [models/whisper-small-finetuned](../models/whisper-small-finetuned)
- top-level `config.json` reflects Whisper-small architecture and generation token settings
- `checkpoint-*` folders include `trainer_state.json`, `rng_state.pth`, tokenizer/config files for intermediate training states
- `SAVE_OK` indicates the script-level save completion marker from training

### Text Classifier Artifact
Location: [models/text_cls_amd_v2.joblib](../models/text_cls_amd_v2.joblib)
- The server expects a dict-like bundle containing `clf` and a `vectorizer` or `vec`.
- Verified risk: `scripts/train_text_cls.py` trains on `hstack([word,char])` features, but saves only `word_v` as `vectorizer`; current startup validation in [server/ws_server.py](../server/ws_server.py) can therefore leave `classifier_ready=False`, forcing keyword-only fallback.
